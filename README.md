## Nothing you cite will break

GitHub redirects the old URLs, web and `git clone` / `fetch` / `push` alike. The
published papers are immutable PDFs on Zenodo and they cite
`github.com/gift-framework/core` dozens of times, so those redirects are
load-bearing infrastructure: the old paths will never be reused.

**One thing does not redirect: GitHub Pages.** The documentation sites moved and the
old addresses return 404 with no forwarding.

| Old documentation URL | Where it is now |
|---|---|
| `gift-framework.github.io/GIFT/` | [arithmon.github.io/K7](https://arithmon.github.io/K7/) |
| `gift-framework.github.io/core/` | [arithmon.github.io/K7-Lean](https://arithmon.github.io/K7-Lean/) |
